# Steering rules (pasted from a doc editor)

The list markers below carry a Unicode space separator, not U+0020.
Ten each: NBSP U+00A0, FIGURE SPACE U+2007, NARROW NBSP U+202F, IDEOGRAPHIC SPACE U+3000.
Forty rules, byte-different from their ASCII twins, identical on every screen.

- keep every module under two hundred lines.
- name booleans with an is or has prefix.
- run the formatter before every commit.
- put integration tests in tests/integration.
- log at info for lifecycle events only.
- pin every dependency to an exact version.
- wrap external calls in a timeout.
- return typed errors from the service layer.
- keep migrations forward-only.
- document any public function over ten lines.
