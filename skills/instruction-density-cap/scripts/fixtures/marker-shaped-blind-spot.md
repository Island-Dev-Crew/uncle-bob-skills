## Code style

**1.** Use two-space indentation
**2.** Prefer named exports
**3.** Keep functions under fifty lines
**4.** Name booleans with an is or has prefix

## Git

**5.** Write imperative commit subjects
**6.** Rebase before opening a pull request
**7.** Squash fixup commits
**8.** Never force-push a shared branch

✅ Run the formatter before pushing
✅ Update the changelog for user-facing changes
🔴 Never commit secrets
■ Keep the dependency list short
