# QA procedure — cart checkout total

You are a human. You are operating this system at the UI. You must prove that the system works.

1. Add 2 copies of the $5.00 item to the cart. Expected: the cart badge reads 2.
2. Click Checkout. Expected: the order total reads $10.00.

The system is proven only when every expected result above was observed. Any miss is a fail, never a note.
