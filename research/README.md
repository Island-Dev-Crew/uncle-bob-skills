# Research briefs — how to read the labels

Seven briefs. They carry the claims that go **beyond** the conversation: history, primary papers, what has and has not been replicated. Claims about the conversation itself belong to [`../01-CONCEPT-LEDGER.md`](../01-CONCEPT-LEDGER.md) instead.

## The transcript these briefs cite

Every brief cites `../source/transcript.txt`. **That file is not in the clone** — it is the whole of someone else's recorded conversation, so this repository cites it and does not redistribute it. [`../source/README.md`](../source/README.md) carries the two commands that regenerate it from the published video; run them once and every transcript citation below resolves.

The briefs used to cite the absolute path of a scratch directory on the machine that wrote them. That path was a citation only its author could follow, which is the same failure as a proof block nobody re-runs.

## The labels

`UNVERIFIED` is a **per-claim** label, not a per-document verdict. It marks a specific sentence whose source was not reached — a paraphrase from a secondary source, an attribution that could not be traced to a primary, a threshold quoted without its experiment. It is never a summary of the brief's overall quality, and a brief may carry sourced claims and `UNVERIFIED` ones on the same line.

So there is no such thing as a brief that is "all verified": there are claims that are sourced, and claims that are marked. A header asserting the first while the body contains the second is exactly the laundering the [first law](../CONTEXT.md) forbids, and one brief here shipped that contradiction until an outside reviewer read both ends of it.
