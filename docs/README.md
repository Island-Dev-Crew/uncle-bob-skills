## What belongs where

| Surface | Audience | Contents |
|---|---|---|
| `README.md` | New users and evaluators | Promise, outcome routes, first skills, installation, verification, and ownership. |
| `skills/` | Operators and agent harnesses | The actual fifty skill contracts, sidecars, scripts, and fixtures. |
| `scripts/` | Maintainers and reviewers | Pack-wide validators and adversarial verification tooling. |

| `research/` and `source/` | Auditors and maintainers | Grounding material and reproducible source notes. |

This repository keeps build history visible because hidden correction is not evidence. Visibility does not require making that history the landing page.
